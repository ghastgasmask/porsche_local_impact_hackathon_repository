Теперь к главному:
Это приложение на Streamlit помогает управлять деньгами компании, прогнозировать кассовые разрывы и распределять средства

Давайте простыми словами разберем, какие файлы и папки здесь есть и за что они отвечают

Главные файлы в проекте
----------------------------
- app.py  Главный файл приложения. Отсюда всё запускается. Он загружает данные из папки data и открывает стартовую страницу
- requirements.txt  Список библиотек, которые нужно установить для запуска программы

Папка data (Данные)
------------------
Здесь хранятся файлы с информацией в формате таблиц (CSV):
!!! СГЕНЕРИРОВАНЫ С ПОМОЩЬЮ PYTHON НА KAGGLE, ЛИБО CHATGPT, НЕКОТОЫРЕ ИЗ НИХ НЕ НАСТОЯЩИЕ !!!
!!! ПОТОМУ ЧТО МЫ НЕ НАШЛИ НОРМАЛЬНЫХ ДАННЫХ !!!

- accounts_balances.csv Список счетов и сколько на них денег прямо сейчас
- transactions_history.csv  История всех платежей
- scheduled_payments.csv  График будущих расходов (кому и когда мы должны заплатить)
- expected_inflows.csv  Ожидаемые будущие доходы (кто и когда заплатит нам)
- holidays_calendar.csv  Календарь праздничных дней (когда банки не работают)
- actions_log.csv  Журнал действий, которые совершил пользователь

Папка pages (Страницы интерфейса, на стримлите находятся слева в колонке)
--------------------------------
Здесь находятся файлы для отображения страниц на экране
1. 1_home.py (Главная панель)  Сводка по всей системе: общий баланс, метрики
2. 2_allocator.py (Перераспределение)  Показывает, где скопились лишние деньги, а где их не хватает
3. 3_cash_flow.py (Прогноз потоков)  График будущих доходов и расходов на 30 дней вперед. Предупреждает о нехватке денег
4. 4_ml_analyzer.py (ИИ-анализ)  Ищет подозрительные платежи и строит прогнозы с помощью машинного обучения
5. 5_reserves.py (Резервы)  Показывает оптимальный объем запасов денег на счетах компании
6. 6_automation.py (Автоматизация)  Настройки системы оповещений и алертов
7. 7_actions.py (Действия)  Страница, где можно перевести деньги, отложить резерв или отменить прошлое действие
8. 8_ai_assistant.py (ИИ-ассистент)  Чат-бот, который понимает обычные вопросы о финансах и может строить графики
9. 9_currency_calculator.py (Конвертер валют)  Простой калькулятор для перевода денег из одной валюты в другую

Папка logs (Логи)
--------------------------
- operation_logs.jsonl  Журнал всех операций в формате JSON Lines. Сюда автоматически записываются действия, запрошенные через ЛЛМ

Папка models (Файлы моделей)
---------------------------
- ml_models.pickle  Сохраненный файл с обученными моделями машинного обучения (используется для предсказания объемов и поиска аномалий на странице анализа)

Папки __pycache__ ( кэш, сгенерирован стримлитом, вроде бы)
--------------------------------
- __pycache__  Технические папки с кэшем Pythonа

Папка modules (Логика)
---------------------
Здесь лежит код, который выполняет все расчеты:
- cash_allocator.py  Рассчитывает, как правильно переводить деньги между счетами
- cash_flow_predictor.py  Прогнозирует баланс на будущее с учетом задержек платежей
- reserve_optimizer.py  Вычисляет идеальный размер финансовых резервов
- ml_analyzer.py  ML-ка для поиска аномалий и прогнозов
- action_executor.py  Выполняет переводы денег и другие действия в системе
- automation_center.py  Проверяет балансы и создает алерты
------------------------------------------
Специальные подпапки в modules:
Код для работы с ЛЛМ-кой Отвечает за общение и память чата:
  - client.py  Подключение к нейросети Groq
  - config.py  Настройки подключения (модель и API)
  - data_context.py  Собирает актуальные данные из таблиц, чтобы ЛЛМ видела их
  - memory.py  Хранит историю переписки в текущей сессии
  - prompts.py  Инструкции для ЛЛМ (как общаться, формат ответов)
------------------------------------------
- modules/charts/  Отвечает за создание графиков по запросам пользователя. Ответ от ЛЛМ
  - chart_generator.py  Код для рисования графиков Plotly
  - chart_parser.py  Извлекает инструкции для рисования графиков из ответа ЛЛМ
  - chart_registry.py  Описание доступных таблиц для ИИ
  - chart_renderer.py  Отображает построенный график на странице
  - chart_validator.py  Проверяет, корректные ли данные ЛЛМ пытается нарисоватЬ. Сураганов, Добавлено гпт
------------------------------------------
- modules/data_modification/  Отвечает за проверку безопасности изменений:
  - confirmation_manager.py  Хранит операции, ожидающие подтверждения от пользователя
  - operation_executor.py  Записывает подтвержденные ИИ-изменения в CSV-файлы
  - operation_logger.py  Записывает лог изменений
  - operation_parser.py  Извлекает инструкции на изменение из ответов ЛЛМ
  - operation_registry.py  Список таблиц и колонок, которые ЛЛМ разрешено менять
  - operation_validator.py  Проверяет безопасность изменений (e.g. отсутствие отрицательного баланса)
  - rollback_manager.py  Код для отката изменений к исходному состоянию. rollback - znachit otkat
